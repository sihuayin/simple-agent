# ADR-0001: Layered system prompt, stable-first for prefix caching

Both providers' prompt caches are prefix-based — DeepSeek's context caching is automatic and only hits when a request fully matches a persisted prefix unit, and Anthropic's `cache_control` breakpoints cache a prefix — so the system prompt is composed as stable-first layers (role definition → general rules → project settings from `AGENTS.md`), maximizing the chance that the repeated prefix is reused across requests. Considered and rejected: explicit Anthropic `cache_control` breakpoints (the current runtime reaches DeepSeek's Anthropic-compatible endpoint, whose cache_control support is undocumented; add them when a real Anthropic key is in play — the layer composition makes that a one-line change), and DeepSeek's `thinking` parameter (deferred; prompt-level step-by-step instructions are enough for now). The prompt is written in Chinese per the user's choice. Downside: advertising tools and a stable system prefix costs tokens on every request; a `--no-tools` opt-out is a possible future mitigation.
