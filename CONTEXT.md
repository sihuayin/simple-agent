# Context

## Glossary

- **conversation**: a single exchange — one prompt in, one model response out. Tools are always available and the model decides whether to call them; when it doesn't, a conversation is exactly one round.
- **message**: one `role` + `content` pair sent to the model. This CLI always sends exactly one user message per conversation.
- **prompt**: the user-supplied input text that becomes the user message.
- **response**: the model's reply to the prompt.
- **model**: the model identifier used for the conversation — per-provider default (`deepseek-v4-flash` / `claude-sonnet-4-5`), overridable via `--model` or that provider's model env var. Model IDs pass through unvalidated: catalogs go stale, so refusing unknown IDs would reject valid models.
- **provider**: the service that supplies the model — currently `deepseek` and `claude`. Selected by the `--provider` flag, the `LLM_PROVIDER` environment variable, or the default.
- **adapter**: the per-provider wrapper that turns one provider's API call into the raw response shape the CLI normalizes. The conversation logic depends on an adapter, never on a specific provider's SDK; adding a provider means adding a registry entry and an adapter.
- **client**: the SDK client an adapter wraps (OpenAI-compatible SDK for `deepseek`, Anthropic SDK for `claude`), constructed from that provider's env vars. Adapters, not clients, are injected into the conversation logic.
- **tool**: a capability the agent can call in agent mode — `read_file`, `write_file`, `edit_file`, `grep`, `glob`, `bash`, `list_files`. Each tool carries a name, a description (what the model sees), JSON-schema parameters, and an implementation that runs against the workspace.
- **tool call**: a request from the model to execute a tool (OpenAI wire: `tool_calls`; Anthropic wire: `tool_use` blocks). The loop executes it and feeds the result back as a **tool result**.
- **agent loop**: the cycle of model output → tool execution → result feedback → next model output, terminating on a final text answer or the iteration cap (default 10 tool rounds). Errors from tools are fed back to the model as results, not crashes.
- **system prompt**: the layered instruction sent to the model — role definition → general rules → project settings. Stable layers come first because both providers' caches are prefix-matched (see ADR-0001).
- **prompt caching**: the provider mechanism for reusing a request prefix across calls — DeepSeek's automatic KV cache and Anthropic's `cache_control` breakpoints. This CLI relies on stable-first ordering rather than explicit breakpoints.
- **layer**: one of the three system-prompt sections (role / rules / project), ordered by stability. The project layer is loaded from the workspace's `AGENTS.md` and is empty when the file is missing.
- **token budget**: the pre-send estimate of context usage — CJK at 1.5 chars/token, everything else at 4 chars/token, plus per-message overhead and the fixed cost of the system prompt and tool schemas. When the estimate (or the API's real usage) crosses the threshold (default 80% of the provider's context window), the loop compacts before sending.
- **compaction**: the reduction of conversation history — rolling summary (keep the last N rounds verbatim, fold older rounds into a `[对话摘要]` message via one extra model call) or truncation (drop the oldest tool results). The `/compact` user command forces a compaction; the marker is never sent to the model.
- **policy**: the security evaluation applied to every tool call — three passes (deny → ask → allow) with ask as the fallback default. Deny covers irreversible commands, allow covers daily operations, ask covers risky actions and all writes; on ask the CLI confirms with the human on a TTY. Rules come from built-in defaults plus the workspace `.rules` file.
- **rule**: one entry in the policy — `{tool, pattern?, action}` where action is `deny`/`ask`/`allow`; a missing pattern makes it tool-level (matches any invocation).
- **protected path**: a path pattern (`.git/**`, `.env*`, …) that forces ask even when an allow rule matched — the extra insurance layer on top of the rule list.
- **streaming**: the transport for every model call — `chatStream` yields `{type:"text"}` deltas as content arrives and a final `{type:"done", raw}` with the fully accumulated response. `chat` is its accumulation (one wire path), so streamed and one-shot responses can never diverge. Each provider's wire format is translated by a pure accumulator: OpenAI chunks (concatenated `delta.content`, indexed `tool_calls` partials) for DeepSeek, Anthropic events (`text_delta` joins, `input_json_delta` partials per tool_use block) for Claude.
- **spinner**: the TTY-only ANSI waiting indicator on stderr (frames ⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏, 80ms). It spins during "waiting" phases (connect, tool rounds, compaction) and stops when text streams. `--no-stream` disables live text printing, not the spinner.
- **memory**: persistent information from past sessions, auto-loaded into every new session's system prompt. Three types: **user** (personal preference, global — loads in every project), **project** (convention, loads only in its source workspace), **feedback** (user correction of agent behavior, project-level). A memory carries a **topic key**; same topic + same type + same scope overwrite (version+1, old text into history), different types on the same topic conflict and are resolved at load: project-level beats global, newest wins within a level, the loser is suppressed but visible. Judgement rule: *"would this still be useful in a new session?"* — transient debug info and one-off task details must not be stored. The agent stores via the `remember` tool (auto, no confirmation); the human owns deletion via `--memory-forget <id>`. Storage: `~/.simple-agent/memory.json` (global) and `.simple-agent/memory.json` in the workspace (project, gitignored).
